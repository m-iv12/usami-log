# ロウ配信ログ

YouTube の配信履歴・配信予定・コラボ配信を3時間ごとに自動で取得し、週表示（バーチカル）と月表示（サムネイル）で見られるページです。GitHub Pages で公開します。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 表示ページ |
| `config.json` | チャンネル、取得開始日、ゲーム名の表記ゆれ、コラボ判定のキーワード |
| `streams.json` | 表示用データ（自動生成。手で編集しない） |
| `cache_*.json` | 取得結果の保存用（自動生成。手で編集しない） |
| `posts.json` | X のポスト |
| `deadlines.json` | グッズなどの締切 |
| `schedule.json` | 枠が立つ前の配信予定（手で追記） |
| `collab_videos.json` | 他チャンネルの配信・動画の URL（手で追記） |
| `collab_exclude.json` | 自動で拾われたが除外したい動画の URL |
| `override.json` | ゲーム分類を手で直したいとき（任意） |
| `fetch_streams.py` | YouTube Data API から取得して表示用データを作る |
| `add_item.py` | ページの「追加」ボタンからの登録を *.json に書き足す |
| `.github/workflows/update.yml` | 3時間ごと・登録時・ファイル変更時に実行し、ページを公開 |

## 初期設定

### 1. YouTube Data API のキーを取得
1. Google Cloud Console（https://console.cloud.google.com/）でプロジェクトを作成
2. 「API とサービス」→「ライブラリ」で **YouTube Data API v3** を有効化
3. 「認証情報」→「認証情報を作成」→「API キー」
4. 作成したキーの「API の制限」で YouTube Data API v3 のみに制限しておく

請求先アカウント（クレジットカード）の登録は不要です。

### 2. GitHub にリポジトリを作成
1. GitHub で新しい **Public** リポジトリを作成
2. このフォルダの中身をすべてアップロード（`.github` フォルダも含める）

### 3. API キーを Secrets に登録
リポジトリの Settings → Secrets and variables → Actions → New repository secret
- Name: `YOUTUBE_API_KEY`
- Secret: 手順 1 のキー

キーは `config.json` やコードには書かないでください。公開リポジトリなので誰でも見られます。

### 4. チャンネルを確認
`config.json` の `channel` を、YouTube チャンネルページの URL にある `@〜` と同じ文字列にします。うまくいかない場合は `UC` で始まるチャンネル ID を入れてください。

`since` は何日まで遡るかです。

### 5. GitHub Pages を有効化
Settings → Pages → Source（Build and deployment）を **GitHub Actions** にします。
手順 6 の実行が終わると `https://<ユーザー名>.github.io/<リポジトリ名>/` で表示されます。このURLを共有してください。

### 6. 初回実行
Actions タブ →「配信データ更新」→ Run workflow（`full_refresh` に `1` を入れると全件を取り直します）。完了すると `streams.json` に配信が入ります。

### 7. 「追加」ボタンを自分の端末で表示する
ページの URL の末尾に `#edit` を付けて一度開くと、その端末（ブラウザ）では右下に「追加」ボタンが表示され続けます。
`#edit` を付けずに URL を共有すれば、他の人の画面にはボタンは出ません。

## 「追加」ボタンからの登録（ふだんはこれだけ）
右下の「追加」から、次の4種類を登録できます。

| 種類 | 入力するもの |
|---|---|
| 他枠の配信 | YouTube の URL を貼るだけ。時刻・サムネイル・チャンネル名は自動取得 |
| 配信予定 | 日付・開始時刻・タイトル・ゲーム・本人の枠か他の人の枠か（告知ポストの URL は任意） |
| ポスト | X の URL を貼るだけ。投稿時刻は URL から自動で読み取り。配信告知かどうかを選ぶ |
| 締切 | 内容・締切日時（初期値 23:59）・公式の告知ポストか販売ページの URL |

「GitHub で登録する」を押すと GitHub の Issue 作成画面が開くので、そのまま **Create** を押します。1〜3分ほどで自動処理が終わり、Issue が「反映しました」のコメント付きで閉じられ、カレンダーに表示されます。

- スマホのブラウザで GitHub にログインしておく必要があります
- 受け付けるのはリポジトリの持ち主（自分）が作った Issue だけです。他の人が同じことをしても反映されません
- 失敗したときは Issue に「登録に失敗しました」とコメントが付きます

以下の「手で追記」は、ボタンを使わずにファイルを直接直したい場合の方法です。

## ポストの追加
`posts.json` に 1 件ずつ追記します（GitHub 上の鉛筆アイコンから編集できます）。

```json
[
  {"time": "2026-10-18T12:00:00+09:00", "kind": "announce", "text": "配信告知", "url": "https://x.com/.../status/..."},
  {"time": "2026-10-18T23:10:00+09:00", "text": "ポスト", "url": "https://x.com/.../status/..."}
]
```

- `kind` を `"announce"` にすると青丸（配信告知）、省略すると白丸（ポスト）
- 最後の行の後ろにカンマを付けないこと

## 配信予定
- **自動**：YouTube で枠（待機所）が立つと、次の自動更新で「予定」（点線のブロック）として表示されます。配信が終わると実際の時刻に置き換わります
- **手動**：枠が立つ前の予定は `schedule.json` に追記します。同じ時間帯（前後3時間）に枠が立つと、手動の予定は自動的に表示されなくなります

```json
[
  {"start": "2026-11-03T20:00:00+09:00", "title": "大会本番", "game": "valo", "own": true, "url": "https://x.com/.../status/..."}
]
```

`end` を書けば終了時刻も指定できます。省略時は2時間の枠で表示します。

## コラボ配信（他チャンネル）
他チャンネルの配信は、本人の配信と時間が重なっていれば、その配信の詳細に「コラボ相手の枠」として並びます。手動で登録したもので、重なる本人の配信がなければ、「本人の枠なし」として単独で表示し、リンクは相手の枠に飛びます。

- **手動（確実）**：`collab_videos.json` に URL を追記します。時刻・サムネイル・チャンネル名は自動で取得します

```json
[
  "https://www.youtube.com/watch?v=xxxxxxxxxxx",
  "https://www.youtube.com/live/yyyyyyyyyyy"
]
```

- **自動**：`config.json` の `collab_channels` に、よくコラボする相手のチャンネル（`@ハンドル` か `UC〜` の ID）を並べます。初期状態は空なので、自動では何も取りに行きません
  - 対象は一覧に書いたチャンネルだけで、インターネット全体は検索しません
  - そのチャンネルの配信のうち、タイトルか概要欄に `collab_keywords`（初期値「小柳ロウ」「Koyanagi Rou」）を含み、**かつ小柳ロウ本人の配信と時間が重なるもの**だけを「コラボ相手の枠」として付けます
  - 本人の配信と重ならないものは、無関係の可能性があるため表示しません。本人の枠がないコラボは「追加」ボタン（他枠の配信）で登録してください
- **除外**：誤って拾われたものは `collab_exclude.json` に URL を追記します

## ゲーム名
- 配信タイトル先頭の【】の中身をそのままゲーム名にします（例：【VALORANT】ランク → VALORANT）。【】がない配信は「その他」になります
- 表記ゆれは `config.json` の `game_aliases` でそろえます（例：「Apex Legends」「APEX」→ APEX）
- VALORANT・APEX・雑談は固定の色、それ以外のゲームは名前ごとに色が自動で決まります
- 個別に直したいときは `override.json` を作成：

```json
{ "動画ID": {"game": "VALORANT"} }
```

## 制限
- 非公開・削除されたアーカイブは取得できません
- メンバー限定配信は、時刻は取得できる場合がありますがリンク先は会員のみ視聴可能です
